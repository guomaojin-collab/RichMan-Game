# Dream Island V4 Design Source

Figma design source: https://www.figma.com/design/GLL8wkuOj1tgCATFNEbI1P

The file contains:
- Dream Island / Game Main (1440x900)
- 2.5D island map composition
- top player HUD
- left navigation for Cards / Stocks / Skills / Map Info
- right Recent Events panel
- property information panel
- central dice action
- landmark/building layer
- reusable UI Design System components

Implementation rule: preserve the existing RichMan game engine and progressively replace only the renderer/UI with this Figma source.
