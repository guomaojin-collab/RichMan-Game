# 财富环游记 RichMan Game

一个可以直接在浏览器运行的大富翁风格网页游戏。

## V1 功能
- 4 位本地玩家轮流游戏
- 掷骰子与棋子逐格移动动画
- 24 格环形棋盘
- 购买地产与收取租金
- 随机事件与税务格
- 经过起点获得奖金
- 玩家资产与地产数量实时显示
- 破产淘汰与最终胜利判断
- 响应式布局，支持桌面和手机浏览器

## 运行
这是一个纯静态网页项目，不需要构建步骤。直接打开 `index.html` 即可运行。

## Cloudflare Pages
连接此 GitHub 仓库后，将 Production branch 设置为 `main`。该项目无需 Build command，输出目录使用仓库根目录即可。
